# Simulation-en-Java-invasion-de-zombies-marins-Poissons-ou-poisons-
Un zombie infecte un corail, qui rejette alors du poison mortel et, sans soin, devient lui-même un zombie. Pour survivre, les poissons doivent trouver des plantes magiques protectrices ou éliminer les zombies, tandis que des robots nettoyeurs soignent les coraux pour stopper l’épidémie. Qui sauvera l’océan ?
